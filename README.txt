# Подарочный сайт — Гродно ❤️

## 1. Куда добавлять новые фотографии

Все фотографии кладутся в папку:

`assets`

Например:

`assets/photo_7.jpg`

### Фотография после вопроса

В `index.html` найди нужный вопрос (`q7`, `q8` и т.д.) и найди внутри него:

`<div class="memory-photo" data-photo="photo_7.jpg">`

Там поменяй имя файла в `src`, если нужно.

После правильного ответа будет:
**вопрос → фото → кнопка «Дальше» → следующий вопрос**

Если фотографии нет, блок автоматически скрывается.

---

## 2. Финальная фотография Туарега

Для финальной страницы я сделал специальное место.

Просто положи фотографию Туарега сюда:

`assets/touareg.jpg`

Больше ничего менять не надо.

Финальная страница сама покажет её вместо заглушки.

Если хочешь использовать другое имя, например `my_touareg.png`, открой `index.html` и в финальном блоке поменяй:

`src="assets/touareg.jpg"`

на:

`src="assets/my_touareg.png"`

---

## 3. Если хочешь добавить фотографию после вопроса 1

В секции `q1` можно скопировать целиком блок:

`<div class="memory-photo"> ... </div>`

из другого вопроса и вставить его перед `<div class="feedback"></div>`.

---

## 4. Главное

Не удаляй папку `assets`, когда будешь загружать сайт на хостинг — именно там будут лежать все фотографии.
